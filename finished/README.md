# finished/

Plans, proposals and notes that have been **carried out**. They stay because
the reasoning is worth keeping and because a decision rediscovered is a
decision argued twice; they move here so that nothing at the top level is both
done and indistinguishable from pending.

The convention is the compiler repository's, which keeps its own `finished/`
for the same reason.

| --- | --- |

| `PLAN-0.2.3.md` | the five-phase plan that put it there, with the measurements and findings each phase produced — including the one conclusion it got wrong and the correction. |

⚠️ **A file here is a record, not a reference.** `OVERVIEW.md` describes the
site as it was before v0.2.3 and `PLAN-0.2.3.md` states figures that have moved
since — 292 rules where there are now 297. For what is true today, read
`CLAUDE.md` and the page.
